Import Products from CSV

Instructions:

  1. Download the CSV template to see the required format
  2. Fill in your product data following the template structure
  3. Make sure category_slug and producer_slug match existing records
  4. Upload your completed CSV file below

Required Fields:

  • sku - Unique product identifier
  • name - Product name
  • category_slug - Category slug (must exist in database)
  • description - Product description
  • price_tnd - Price in TND
  • impact_description - Social impact description
  • impact_school - Beneficiary school
  • impact_quantity - Number of items provided
  • impact_item - Type of item provided

Optional Fields:

  • name_en, description_en, price_eur, stock_quantity, weight, producer_slug
  • Boolean fields: is_active, is_featured, is_natural, is_organic, is_handmade, is_vegan (use: true/false)
