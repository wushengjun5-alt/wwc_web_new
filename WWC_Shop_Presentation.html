Mission & Vision
Qui est WWC et pourquoi cette boutique ?

Qui est Wallah We Can ?

Wallah We Can (WWC) est une association caritative axée sur l'initiative GreenSchool. Les parents d'élèves travaillent sur des fermes pour produire des biens artisanaux — huiles essentielles, produits naturels, aliments biologiques — issus de régions rurales de Tunisie et d'autres pays en développement.

Chaque achat effectué sur la boutique soutient directement les élèves de l'école Sidi Mechreg en finançant des repas, du matériel scolaire et d'autres ressources essentielles.

Tagline central : « Grâce à votre achat de [produit], 6 barres énergétiques seront fournies aux élèves de Sidi Mechreg. »

Ce que cette boutique accomplit

🛒 Commerce équitable numérique

Une vitrine en ligne permettant aux artisans tunisiens et africains de vendre leurs produits directement à des clients en Europe et dans le monde entier.

📊 Impact transparent

Chaque produit affiche son impact social concret : nombre de repas financés, matériel fourni, école bénéficiaire.

🏢 Support B2B

Les entreprises peuvent commander en gros avec des tarifs professionnels, des factures dédiées et un flux d'approbation distinct.

Étapes détaillées

1

Page d'accueil

Le client arrive sur la boutique. Il voit un héro accrocheur, les produits mis en avant, et un aperçu de l'impact social de ses futurs achats.

2

Navigation dans la boutique

Il peut filtrer par catégorie (Soins, Nutrition…), rechercher un produit par mot-clé, filtrer par prix ou badge (bio, vegan…).

3

Page produit

Détails complets : photos, description, ingrédients, impact social, avis clients, profil du producteur. Ajout au panier avec sélection de quantité.

4

Panier

Récapitulatif des articles sélectionnés. Le client peut modifier les quantités, supprimer des articles, voir les frais de port et le total.

5

Tunnel de paiement

Saisie des coordonnées, sélection de l'adresse de livraison (sauvegardée ou nouvelle), adresse de facturation, mode de paiement (Stripe carte ou virement bancaire).

6

Confirmation de commande

Page de succès affichant le numéro de commande (WWC-YYYYMMDD-XXXX). Un email de confirmation est envoyé automatiquement.

7

Espace client — Mon Compte

Le client peut suivre l'état de sa commande (En cours, Expédié, Livré), voir ses adresses sauvegardées, gérer sa liste de favoris et ses paramètres.

8

Impact visible

Sur la page Impact, le client peut voir concrètement comment son achat a contribué : « Grâce à vos achats, 42 repas ont été fournis ce mois-ci. »

Guide Utilisateur — Actions pour le Staff WWC
Comment gérer la boutique au quotidien

📦 Gérer les Commandes

1

Accéder aux commandes

Dans le tableau de bord admin, cliquez sur Commandes dans le menu gauche. La liste affiche toutes les commandes triées par date.

2

Changer le statut

Ouvrez une commande → cliquez sur Modifier le statut → sélectionnez : En attente / Payé / En traitement / Expédié / Livré / Annulé.

3

Ajouter un numéro de suivi

Lors du passage au statut Expédié, un champ apparaît pour saisir le numéro de tracking. Le client reçoit un email automatique.

⚠️ Important : Lorsque vous annulez une commande, le stock est automatiquement restauré. Pas besoin de le faire manuellement.

🛍️ Ajouter / Modifier un Produit

1

Nouveau produit

Admin → Produits → cliquez sur le bouton orange + Nouveau produit.

2

Remplir les informations

Nom (FR/EN/AR), description, catégorie, producteur, prix EUR et TND, stock initial, badges (bio, vegan…), message d'impact social.

3

Ajouter des images

Téléchargez jusqu'à 5 photos. La première image sera l'image principale affichée dans la boutique.

4

Activer le produit

Cochez Actif pour le rendre visible dans la boutique. Laissez inactif pour le préparer sans le publier.

👥 Gérer les Clients

1

Consulter la liste

Admin → Clients → liste de tous les clients avec leur type (B2C/B2B), date d'inscription et total de commandes.

2

Approuver un client B2B

Les demandes B2B apparaissent avec le statut En attente. Cliquez sur le client → bouton Approuver pour activer les tarifs grossiste.

💚 Consulter les Donations

1

Liste des dons

Admin → Donations → affiche tous les dons avec montant, donateur (ou anonyme), pays bénéficiaire et statut de paiement Stripe.

2

Exporter les données

Utilisez le bouton Export CSV pour télécharger les dons et les partager avec la comptabilité ou les bailleurs de fonds.

📦 Utiliser le Box Builder (Composer Ma Box)

Le module Composer Ma Box permet aux clients de choisir leurs produits dans une sélection prédéfinie pour créer une box personnalisée. Le modèle de données est prêt côté serveur ; l'interface de configuration admin est en cours de développement (Phase 3).

Ce qui fonctionne déjà

Les modèles ComposableBox sont en base de données. On peut créer des boxes depuis l'interface Django admin native (backend/admin/) en définissant les produits éligibles et les quantités min/max.

Ce qui reste à faire

Une interface admin visuelle pour créer et gérer les boxes, et une page client interactive avec sélection des produits et aperçu en temps réel.

Fonctionnalités B2B (Clients Professionnels)
Ce qui différencie un client entreprise d'un client particulier

Qu'est-ce qu'un client B2B ?

Un client B2B (entreprise) peut s'inscrire pour obtenir des tarifs professionnels réduits sur les achats en gros. Ce profil est distinct du client particulier (B2C) et nécessite une validation manuelle par l'équipe WWC.

Avantages B2B

  • Prix de gros configurables par produit
  • Quantités minimales de commande
  • Adresse de facturation distincte (siège social)
  • Factures avec mentions légales entreprise

Flux d'approbation B2B

1
Inscription B2B

L'entreprise s'inscrit en sélectionnant le type « Professionnel » et renseigne son SIRET / numéro TVA.

2
Statut « En attente d'approbation »

Le compte est créé mais limité aux tarifs B2C. Une notification est envoyée à l'admin WWC.

3
Validation manuelle

L'admin WWC examine la demande dans Admin → Clients et clique sur Approuver.

✓
Compte B2B activé

Le client accède aux tarifs professionnels et peut passer des commandes en gros.

Différences techniques B2B vs B2C

Intégration Stripe — Paiements en Ligne
Comment fonctionnent les paiements sécurisés

Comment ça fonctionne ?

Stripe est le prestataire de paiement utilisé par des millions de boutiques (Amazon, Shopify…). WWC Shop l'intègre pour accepter les cartes bancaires de façon 100% sécurisée sans jamais stocker les numéros de carte.
1

Le client paie

À la fin du tunnel de paiement, il entre ses informations de carte sur une page sécurisée Stripe (chiffrement SSL).

2

Stripe traite le paiement

Stripe vérifie la carte, débite le montant en euros (EUR) et envoie une confirmation sécurisée à la boutique.

3

Webhook de confirmation

Stripe envoie un signal automatique (webhook) à la boutique : « Paiement réussi ». La commande passe alors au statut Payé et l'email de confirmation est envoyé au client.

4

Virement vers WWC

Stripe verse les fonds sur le compte bancaire WWC selon la fréquence paramétrée (quotidienne ou hebdomadaire).

Ce que WWC doit faire

✓ Déjà configuré : L'intégration Stripe est complète. Les clés de test permettent de valider des paiements avec des cartes fictives.
⚠️ À faire avant le lancement :
  1. Créer un compte Stripe sur stripe.com
  2. Remplacer les clés TEST par les clés LIVE dans les paramètres
  3. Configurer le webhook URL dans le dashboard Stripe
  4. Vérifier le compte Stripe (KYC — document d'identité)

Modes Test vs Production

Mode Usage Carte test
TEST Développement / validation 4242 4242 4242 4242
LIVE Production (vrais paiements) Carte réelle requise
Politique de devise :
Stripe traite uniquement les paiements en EUR. Les clients en Tunisie qui souhaitent payer en TND utilisent le virement bancaire (hors Stripe).

🔐 Flux d'authentification

Client (JWT)

1. POST /auth/login/ → reçoit access (5min) + refresh (7j)
2. Stockés dans localStorage (wwc_access_token, wwc_refresh_token)
3. Chaque requête API : header Authorization: Bearer <access>
4. Si 401 → refresh automatique via POST /auth/token/refresh/

Plugin WordPress (Api-Key)

Les pages admin WP appellent directement l'API Django avec le header Authorization: Api-Key <ADMIN_API_KEY>. Ce mécanisme est indépendant des tokens JWT clients. La clé est stockée dans les options WP (wwc_admin_api_key).

Comment gérer la boutique au quotidien, sans connaissances techniques
Pour l'équipe WWC : Ce guide explique chaque action de gestion de la boutique en language simple. Pas besoin de savoir coder — tout se fait depuis l'interface d'administration.

🔑 Accéder à l'administration

Tableau de bord admin boutique

Adresse : votresite.com/admin (ou le chemin configuré)
Vous y trouverez : commandes, produits, clients, donations, stats.
Connexion avec votre identifiant et mot de passe administrateur.

Administration WordPress

Adresse : votresite.com/wp-admin
Dans le menu gauche : WWC Shop → vous trouverez les tarifs de livraison et le taux de change.
Les produits et commandes se gèrent depuis le tableau de bord dédié, pas depuis WordPress.

📦 Gérer les Commandes — Étape par Étape

1

Voir les nouvelles commandes

Allez dans Admin → Commandes. Les nouvelles commandes apparaissent en haut avec le statut En attente (paiement par virement) ou Payé (paiement Stripe confirmé automatiquement).

2

Comprendre les statuts de commande

En attente → Commande reçue, paiement non confirmé (virement en attente)
Payé → Stripe a confirmé le paiement automatiquement
En traitement → Vous avez commencé à préparer le colis
Expédié → Colis envoyé, numéro de tracking saisi
Livré → Client a reçu sa commande
Annulé → Commande annulée, stock automatiquement restauré

3

Changer le statut d'une commande

Cliquez sur le numéro de commande → ouvrez le détail → cliquez sur le bouton Modifier le statut → choisissez le nouveau statut → Enregistrer. Le client reçoit une notification automatique.

4

Ajouter un numéro de suivi (tracking)

Quand vous expédiez le colis, passez le statut à Expédié. Un champ apparaît pour saisir le numéro de tracking de votre transporteur (La Poste, DHL, Chronopost…). Une fois saisi, le client peut suivre son colis.

5

Traiter un remboursement

Les remboursements Stripe se font depuis dashboard.stripe.com → Paiements → trouver la transaction → bouton Rembourser. Ensuite, repassez la commande au statut Annulé dans l'admin boutique pour que le stock soit restauré automatiquement.

🛍️ Ajouter un Nouveau Produit — Champ par Champ

1

Ouvrir le formulaire

Admin → Produits → bouton orange + Nouveau produit en haut à droite.

2

Informations de base

Nom (FR) : Nom du produit en français — ex. "Huile d'Argan Bio 100ml"
Nom (EN) : Traduction anglaise — ex. "Organic Argan Oil 100ml"
Nom (AR) : Traduction arabe (si disponible)
Slug : S'auto-remplit — l'identifiant URL du produit (ne pas modifier)
Catégorie : Choisir parmi Soins, Nutrition, Bien-être, Maison, Coffrets
Producteur : Choisir le producteur partenaire dans la liste

3

Prix et stock

Prix EUR : Prix de vente en euros pour les clients internationaux (ex. 18.50)
Prix TND : Prix en dinars tunisiens pour les clients locaux (ex. 55.00)
Prix de gros (B2B) : Prix réduit pour les clients professionnels — laisser vide si idem B2C
Stock : Quantité disponible. Le système décompte automatiquement à chaque vente.

4

Description et impact

Description : Texte détaillé du produit (ingrédients, utilisation, origine)
Message d'impact : Ce que finance cet achat — ex. "Finance 3 repas scolaires pour les élèves de Sidi Mechreg". Ce texte apparaît sur la fiche produit et dans le panier.

5

Images et badges

Images : Téléchargez jusqu'à 5 photos. La première sera l'image principale dans la boutique. Préférez des photos carrées (1:1) de bonne qualité.
Badges : Cochez les caractéristiques du produit : BIO, Vegan, Artisanal, Nouveau, Vedette — ils s'affichent sur la carte produit.

6

Activer le produit

Cochez Actif pour le rendre visible dans la boutique. Vous pouvez préparer le produit sans le publier — il sera invisible pour les clients tant que "Actif" n'est pas coché. Cliquez Enregistrer.

👨‍🌾 Ajouter un Producteur

1

Créer le profil

Admin → Producteurs → + Nouveau producteur. Remplir : nom, pays, région, photo, biographie, lien vers ses produits. Le profil apparaît sur la page Producteurs et sur les fiches produits.

🏢 Approuver un Client B2B

1

Trouver la demande

Admin → Clients → filtrez par type "B2B en attente". Les demandes d'entreprises y apparaissent avec le statut En attente d'approbation.

2

Valider ou refuser

Ouvrez le profil client → vérifiez les informations (société, SIRET/numéro TVA) → cliquez Approuver pour activer les tarifs professionnels, ou Refuser avec un message explicatif.

💚 Consulter et Gérer les Donations

1

Liste des dons

Admin → Donations → liste de tous les dons avec : montant, donateur (ou "Anonyme"), pays bénéficiaire, date, statut paiement Stripe.

2

Gérer les pays et projets

Admin → Donations → Pays : vous pouvez ajouter/modifier les pays bénéficiaires avec leur image et description. Admin → Donations → Projets : les projets spécifiques auxquels les dons sont alloués.

🚚 Modifier les Tarifs de Livraison

1

Via WordPress admin

WordPress Admin → WWC Shop → Tarifs de livraison. Vous voyez la liste des pays. Cliquez Modifier sur un pays pour changer le tarif (en TND) et le seuil de livraison gratuite (montant à partir duquel la livraison est offerte).

💱 Modifier le Taux de Change TND/EUR

Ce taux sert à convertir les prix TND en EUR pour les clients européens. Il doit être mis à jour régulièrement pour refléter le taux réel.

Où : WordPress Admin → WWC Shop → Paramètres du site → champ "Taux de change TND → EUR".

Exemple : Si 1 EUR = 3.39 TND, entrer 0.295 (= 1/3.39). Vérifier le taux actuel sur Google ou XE.com.

Résumé du projet — Mars 2026
La boutique WWC Shop dispose d'un backend Django complet (50+ endpoints API REST, paiements Stripe, gestion des commandes, impact social, B2B, donations). L'interface client couvre l'ensemble du parcours d'achat avec support trilingue FR/EN/AR. Le tableau de bord admin permet à l'équipe WWC de gérer produits, commandes, clients, donations, tarifs et taux de change. Le plugin WordPress est prêt à être connecté à un site existant.

Les étapes restantes avant le lancement public sont : SSL + déploiement serveur, clés Stripe LIVE, email de vérification, email d'expédition, et le chargement des vrais produits avec photos. Estimé : 2–4 semaines de travail technique.
